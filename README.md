# ThreadConcept

Projeto em Java desenvolvido para demonstrar e praticar conceitos de concorrência e o uso de Threads.

## Sobre o Projeto

O sistema simula um cenário prático de processamento concorrente (envolvendo entidades como restaurante, pedidos e atendimento), permitindo entender o funcionamento da execução paralela e gerenciamento de processos em Java.

## Estrutura do Projeto

* `Restaurante.java`: Classe principal que gerencia o fluxo de execução e a inicialização das operações.
* `Pedido.java`: Define a estrutura e os dados referentes aos pedidos realizados.
* `souiro.java`: Implementa a lógica de manipulação e execução concorrente (Threads).

## Tecnologias Utilizadas

* Java
